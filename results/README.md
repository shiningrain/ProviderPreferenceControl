# Results

This directory will contain sanitized experimental results.

Recommended contents:

- main table summaries;
- ablation summaries;
- sensitivity summaries;
- judge score summaries, if released;
- scripts or metadata explaining how each summary was produced.

Prefer compact JSON, CSV, or Markdown summaries. Do not include raw logs, private run tags, machine paths, API usage records with account identifiers, or unsanitized model outputs.
Each result file should include the dataset split, method name, metric
definition, and the command or script used to generate the summary.
